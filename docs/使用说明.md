# 潮线使用说明

> 潮线（Tideline）使用说明。对应插件版本 0.9.7，最后整理于 2026-11-17。
> 第一次用，先看「[[#快速上手：五分钟用起来]]」和「[[#名词小词典]]」；想知道某个功能怎么用，直接跳到对应页面的章节。
> 潮线是一个画在纸上的「航海日志」：你的任务、项目、目标、人物、想法、书和日记，都是你自己 vault 里的普通 Markdown 笔记，潮线只是把它们画成一本可以操作的手绘册子。

## 一、先认识潮线

### 1.1 怎么打开

- 在 Obsidian 里按 `Ctrl/Cmd + P`，运行命令「打开潮线」。
- 潮线会作为一个标签页打开，标签名叫「潮线」。

### 1.2 界面布局

- **左侧栏**：九个入口，从上到下是 指引、项目、任务、思索、今日、复盘、知识库、大脑、设置。当前所在页会带一条下划线。
- **顶部**：左边是日期大数字（几号），旁边写着月份、星期、第几周和当前时间。右边是「记录」按钮和罗盘。
- **中间**：当前页面的内容，页面下方是一幅会轻轻晃动的手绘风景，每一页的风景不同。
- **底部左侧**：做了删除、完成之类的操作后，会弹出一张小纸条，上面有「撤销」。

### 1.3 数据放在哪里

潮线不自己存数据库，所有内容都写回 vault 里的笔记：

| 内容 | 存放位置 |
| --- | --- |
| 任务 | `任务/` 文件夹，一条任务一篇笔记 |
| 项目 | `项目/` |
| 目标 | `目标/` |
| 人物 | `人物/` |
| 想法 | `想法/` |
| 文献 | `文献/` |
| 书籍 | `书籍/` |
| 日记（每天一篇） | `日记/`，文件名是日期，比如 `2026-11-17.md` |
| 季度复盘 | `季度/` |
| 清单、快捷筛选、习惯、每日问题、生命之轮领域、想法标签 | `潮线/配置.md` |
| 日历订阅的备用日程 | `潮线/日程.md` |

所以你随时可以在 Obsidian 里直接改这些笔记，潮线会跟着更新。删除任务、目标、人物时，笔记进 Obsidian 的回收站，不会直接消失。

### 1.3 示例笔记

首次起航时可能放进一些示例笔记，它们用淡墨和一个「例」字标出，**不计入统计**。可以在 设置 › 数据 里一键清除。

## 快速上手：五分钟用起来

1. **打开**：`Ctrl/Cmd + P`，运行「打开潮线」。
2. **记一件事**：点右上角「记录」，选「任务」，写「明天下午3点交报告 !高」，回车。它会进「任务」页的收件箱。
3. **整理任务**：到「任务」页，把任务拖到左边的某个清单或项目上；点任务打开详情，写正文，输入 `@人名` 把它挂给某个人，输入 `#项目名` 关联项目。
4. **看今天**：到「今日」页，挑出今天最重要的几件事，做完就打勾，顺便填一下习惯、睡眠和投入的时间。
5. **回头看**：到「复盘」页看这一天、这一周、这一季；到「大脑」页看你的项目、任务、人物、想法是怎么连在一起的。

不知道某个按钮是做什么的？打开 设置 › 设备 › 悬停功能提示，鼠标停上去就会说明。

## 二、全局操作

### 2.1 切换页面

- 点左侧栏的入口。
- 点右上角的**罗盘**，打开「八层小地图」，在里面点选要去的页面。罗盘的指针只显示你现在在哪一层。
- 换页时只有纸面滑动的过渡；如果你在系统里开启了「减少动态效果」，或在设置里把「过场」设成「关闭」，会直接切换。

### 2.2 记录（记一笔）

右上角的「记录」按钮，是整个潮线里最快的录入口。

1. 点「记录」，上方展开一条纸条，顶部是类别图标。
2. 选类别：**项目、书籍、文献、想法、任务、随手记、成就、感恩**。每个图标下面写着名称。
3. 输入内容，按 `Enter` 保存，`Shift + Enter` 换行。
4. **输入 `#` 或 `@` 时，下面会弹出已有的内容**：任务里 `#` 列出清单、项目和已有标签，`@` 列出人物；想法里 `#` 列出已有的想法标签，`@` 列出人物；书籍、文献里 `#` 列出已有的关键词。用上下键选、`Enter` 或 `Tab` 插入，也可以直接点。**不选就是新建**：接着往下打，列表最后一项会变成「新建标签 · xxx」，打完整个名字直接回车，就按你打的新建。`Esc` 关掉弹窗。弹窗会根据上下哪边空间大，自己选择朝上还是朝下展开。

各类别的输入提示和去向：

| 类别 | 怎么写 | 保存到哪里 |
| --- | --- | --- |
| 任务 | 「记一件任务，默认进收件箱」，可以写 `明天`、`#清单`、`@人`、`!高` | 新建一篇任务笔记，默认进收件箱，不会自动排到今天 |
| 想法 | 「记一个想法」，可以用 `#标签` | 新建一篇想法笔记 |
| 随手记 | 「此刻想到了什么」 | 写进当天日记里的「## 随手记」 |
| 成就 | 「今天做成了什么」 | 记进当天，复盘里能看到，记错了可以撤销 |
| 感恩 | 「今天感谢什么」 | 记进当天 |
| 项目 | 「新项目的名字」 | 新建一篇项目笔记 |
| 书籍 | 输入书名，回车添加，可用 `#标签` | 新建一篇书籍笔记，阅读阶段默认是「想读」，类型留空 |
| 文献 | 输入文献标题，回车添加，可用 `#标签` | 新建一篇文献笔记，类型留空，自己填 |

### 2.3 搜索全部笔记

- 按 `/` 打开「搜索全部笔记」，输入关键词，搜索所有笔记的标题和正文。
- 结果太多时，会提示「共 N 个文件，显示前 N 个；可增加关键词缩小范围」。
- 搜索范围包括任务、想法、提示词、项目、人物、文献和书籍。

### 2.4 设置

左侧栏最下面的「设置」，或 Obsidian 的 设置 › 第三方插件 › 潮线。详见[[#十一、设置]]。

### 2.5 撤销

- 完成任务、删除任务、删除人物或目标、记错成就，都会在左下角出现一张带「撤销」的纸条，**5 秒内**可以撤回。
- 在任务页里按 `Ctrl/Cmd + Z` 也相当于点这张纸条上的撤销。

### 2.6 悬停提示

设置 › 设备 里有「悬停功能提示」，默认关闭。打开后，鼠标停在图标上会说明这个图标是做什么的。

## 三、任务页

任务页分三块：**左边是导航和清单，中间是任务列表，右边是任务详情**。这一页自带的手绘比喻是一座货仓：任务是货单，人物是邮包，清单是木箱，归档是角落的旧箱子。

### 3.1 左边：导航

- **全部**：所有未归档清单里的任务。
- **今天**：日期是今天的任务。
- **接下来**：从明天起未来 7 天内的任务。
- **收件箱**：没有清单、没有项目的任务，也就是还没整理的。
- **清单**：你自己建的清单（比如「学习」「生活」），每个后面有未完成数量。
- **项目**：所有进行中、计划中、暂停的项目，后面是未完成任务数。把任务拖到某个项目上，就归入这个项目。
- 点一次是选中这个视图，再点一次取消。

### 3.2 顶部：人物邮包

- 页面顶部那一排挂着的邮包，每个对应一个人物，用来表示「待沟通」的任务。
- 点一个邮包：只看和这个人相关的待沟通任务。再点取消。
- 把任务拖到邮包上，就把任务挂给这个人。
- 邮包最前面的 `+` 新建人物。人物超过 4 个时，最后一个邮包是「还有 N 人」，点开可以搜索，也能把任务拖上去再挑人。
- 联系频率到了还没联系，邮包上会挂一个提醒色的小签，并排到最前。

### 3.3 中间：任务列表

**顶部工具行**

- **搜索框**：见 3.5。
- **+**：展开或收起「新建任务」输入框。
- **书签图标**：把当前的筛选条件保存成快捷筛选。
- **快捷筛选行**：比如「写作」「待沟通」「最近完成」。点一下应用，再点取消；`＋` 新增，`✎` 编辑。

**分组**

任务按日期分组：今天、接下来、无日期、已完成等。点分组标题可以折叠或展开；「已完成」默认是收起的。

**一条任务行**

- 最左边是日期（几号），然后是完成圈，然后是任务名。
- 右边会显示时刻、子任务进度、检查项进度、标签、评论数。
- 鼠标停在行上，右边出现「···」菜单按钮。

### 3.4 新建任务

三种方式：

1. 点中间的 `+`，在出现的输入框里写，回车保存。
2. 在任务页按 `n`（光标不在输入框里时）。
3. 用右上角的「记录」。

新建任务时，它会**归到你当前所在的视图**：在「今天」里建，日期就是今天；在某个清单里建，就进这个清单；在某个项目里建，就挂到这个项目；在「接下来」里建，日期是明天；在「已完成」里建，会自动切回「全部」。

输入框里可以直接写自然语言，潮线会自动识别并填好，下面会实时显示识别结果。详见[[#12.1 任务快速输入语法]]。

输入 `#`、`@`、`!` 等符号时，会弹出候选：

- `@` 列出人物，没有的话可以「新建人物」。
- `#` 列出清单、项目、标签。
- `!` 列出优先级。
- 用 `↑` `↓` 选，`Enter` 或 `Tab` 确认，`Esc` 关闭。
- 中文输入法打拼音时，这些键不会被拦截，不会出现拼音被直接保存的问题。

### 3.5 搜索

在搜索框里输入，会实时过滤列表。

- 能搜到：**任务名称、所属项目、所属清单、标签、相关人物**。
- 多个词用空格隔开，要**同时满足**，比如「课程项目 小林」只显示课程项目里关联了小林的任务。
- 开头的 `#`、`@` 会被忽略，搜 `#作业` 或 `@小林` 都可以。
- 搜索时在**全部任务**里查找，不受左边当前选中的清单或「今天」等筛选限制，已完成的也在内。
- 没有结果时会说明，并给出「清除搜索」。

### 3.6 对任务的操作

**完成与重开**

- 点任务前面的圆圈，或选中后按 `空格`、`Ctrl/Cmd + Enter`。
- 完成时先划一道墨，5 秒内可以撤销。
- **重复任务**完成后，会留一份完成记录，原任务自动顺延到下一次，检查项清空；撤销时一并撤回。
- 已完成的任务，再点一次就是重新打开。

**打开详情**

点任务行，右边出现详情。按 `Enter` 会把光标直接放进正文。

**移动 / 排序 / 改日期（拖动）**

- 拖到左边「今天」「收件箱」「某个清单」「某个项目」上：改变归属或日期。
- 拖到另一条任务上：调整顺序，或拖成子任务。
- 拖到分组标题上：改成这一组的日期。
- 拖到顶部邮包上：挂给这个人。
- 拖到「最近完成」：直接完成。
- 拖到右下角的归档箱：放弃这条任务，可撤销。
- 拖动时有一个半透明的任务影子跟着指针，落点是一个圆角虚线框。

**菜单（行上的「···」，或右键，或 `Shift + F10`）**

- 顶部可以直接改日期和优先级。
- 「移动到」：清单、今天、收件箱、某个人等，有二级菜单，指针移上去就展开。
- 「待沟通」：选择要沟通的人。
- 「关联项目」：选一个项目。
- 其他：置顶、复制、删除等。
- 选了多条任务时，菜单作用于整组。

**多选与批量处理**

- `Ctrl/Cmd + 点击`：加选或取消。
- `Shift + 点击`：连续选一段。
- `Ctrl/Cmd + A`：在列表里全选。
- 多选后出现批量面板：批量完成、移动、改优先级、删除等。
- `Esc` 取消选择。

**删除**

选中后按 `Delete` 或 `Ctrl/Cmd + Backspace`。删除可以撤销，撤销纸条消失后才进 Obsidian 回收站。

### 3.7 键盘操作一览

光标不在输入框里时（在任务页）：

| 按键 | 作用 |
| --- | --- |
| `↓` / `j` | 选中下一条 |
| `↑` / `k` | 选中上一条 |
| `Home` / `End` | 跳到第一条 / 最后一条 |
| `Shift + ↓/↑` | 向下 / 向上扩选 |
| `空格` / `Ctrl/Cmd + Enter` | 完成或重开 |
| `Delete` / `Ctrl/Cmd + Backspace` | 删除 |
| `Enter` | 进入正文编辑 |
| `Alt + 1 / 2 / 3 / 4` | 优先级设为 低 / 中 / 高 / 最高 |
| `Alt + →` / `Alt + ←` | 缩进成子任务 / 取消缩进 |
| `n` | 新建任务（光标放进输入框） |
| `p` | 置顶或取消置顶 |
| `Ctrl/Cmd + A` | 全选 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Esc` | 取消选择、关闭弹层 |
| `Shift + F10` 或菜单键 | 打开当前任务的菜单 |

### 3.8 右边：任务详情

详情是一张纸，从上到下是：

**顶部条**

- 最左是完成框。
- 然后是日期（点开可以设**日期、时刻、提醒、重复**）。
- 右边有优先级小旗（点开选最高 / 高 / 中 / 低），再往右的「‹」折回详情。

**标题行**

- 标题可以直接点进去改，回车保存，`Esc` 放弃。
- 标题右边有四个图标：
  - **标签**（添加或移除标签）。
  - **待沟通**（添加或移除待沟通的人）。
  - **关联项目**（添加或修改项目）。
  - **检查项**（把任务在「文本」和「检查项」模式之间切换）。
- 最后面还有一个**添加子任务**图标，点它会在下面展开子任务输入框，光标自动落进去，回车添加，可以连续添加。

**标签条**

标题下面的小胶囊：项目（点击打开项目）、人物（点名字打开人物纸，点 × 取消待沟通）、标签（点 × 去掉）。

**提示行**

正文上方一行淡色小字：「`@` 关联人物 　`#` 关联项目 / 清单 / 标签 　`/` 插入格式」，提醒你正文里可以用这三个符号。

**正文**

正文是 Obsidian 自带的编辑器，所见即所得，支持所有 Markdown。额外有三个触发符：

- 输入 `/`，弹出插入菜单：一级标题、二级标题、三级标题、无序列表、有序列表、检查项、引用、分割线、子任务、标签、关联笔记。
- 输入 `@`，弹出人物候选。选中后，这个人会变成详情标题下的「待沟通」小胶囊，并且任务标为「待沟通」；输入的那段 `@…` 会从正文里删掉。名字不存在时可以直接新建人物。
- 输入 `#`，弹出清单、项目、标签候选：
  - 选**项目**：关联该项目，标题下的项目胶囊更新。
  - 选**清单**：任务移到该清单。
  - 选**标签**：给任务加上这个标签，也可以直接新建标签。
  - 同样用 `↑` `↓` `Enter` `Tab` `Esc`，也可以直接点。
  - 候选菜单会一直显示，直到你选中、按 `Esc`、把符号删掉，或点到别处。
  - 选择后左下角会有撤销纸条。
- `@`、`#` 只有出现在行首或空格后才会弹出，`a@b.com`、`C#` 不会误触。

**检查项模式**

点标题右边的「检查项」图标切换。上面是一小段描述，下面是一条条检查项：点方框勾选，回车添加下一项，在空检查项里按退格删除这一项，`↑` `↓` 在项之间移动。

**子任务**

- 正文下面的「子任务」区块，标题后面写着完成数 / 总数。
- 每条子任务有自己的勾选框，可以完成、重新打开。
- 添加方式：点标题行最后那个「添加子任务」图标，或在正文里输入 `/` 选「子任务」，或在列表里把一条任务拖到另一条上、按 `Alt + →` 缩进。
- 在大脑页里，子任务会画一条线连到它的父任务。

**评论**

底部的评论图标：展开后可以写一条评论，回车添加，每条带日期时间，可删除。

**底部栏**

- 左边是**所在清单**，点开可以搜索清单或项目来移动任务。
- 右边是**A（文本样式）**：点开出现一条工具栏，有标题、加粗、斜体、删除线、高亮、检查项、无序和有序列表、引用、代码、链接、分割线等；鼠标停在按钮上会提示名称，提示显示在按钮上方。
- 最右是**评论**。
- 更多操作（置顶、复制、删除等）在中间列表里该任务行的「···」菜单，或右键。

### 3.9 清单管理

- 左边清单区下面的 `+`：新建清单，点了直接在右边输入名字。
- 右键某个清单：改名，或归档（归档的清单不在导航里显示）。
- 清单信息存在 `潮线/配置.md` 里。

### 3.10 人物（在任务页里管理）

- 点邮包打开**人物纸**，上面可以：
  - 改名、改头像字（一两个字）。
  - 设置**联系频率**：不提醒 / 每周 / 每两周 / 每月 / 每季度。
  - 看上次联系是哪天（取「记录」里最晚的日期）、还有几件待沟通的事、关联的项目。
  - **记一笔**：输入后回车，带今天的日期追加进这个人的笔记里的「记录」。
  - **见面了**：逐件勾选「谈过了 / 做完了 / 下次再说」，写下谈了什么，结论写进记录，跟进事项变成新任务（写 `@名字` 就挂到这个人身上）。
  - **删除**：5 秒内可撤销。
- 在货单输入框里打 `@新名字`，可以直接新建人物。

### 3.11 其他

- **马灯**：点页面里的马灯，可以点亮或熄灭货仓的灯光。
- **归档箱**：右下角的旧箱子，拖进去就放弃这条任务。
- **自动保存**：在任务详情里打字，停手约 1 分钟后自动保存；离开输入框、切换窗口、关闭页面时会马上保存。
- 在任务详情里打字时，保存引起的整页重画会等你停手再做，光标和正文不会跳动。
- 空的任务页会写一句怎么开始，列表为空时点「新建任务」即可。

## 四、项目页

项目页用「海」来比喻：不同状态的项目，是停在不同水域的船。

### 4.1 四片水域

从左到右：

- **港口**：计划中的项目。
- **航道**：进行中的项目。
- **海湾**：暂停的项目。
- **对岸**：已完成的项目。

### 4.2 基本操作

- **点船标**：展开这个项目的详情（海图折回，详情纸展开）。
- **把船标拖到另一片水域**：直接改变项目的状态。
- 点左上「新建项目」：输入项目名字，回车创建。
- 右上有「切换项目列表」：在海图和列表之间切换；还可以展开「归档项目」。

### 4.3 项目详情

- **项目名**：直接点进去改。改名后，所有任务里指向这个项目的名字会一起更新。
- **项目状态**：计划中 / 进行中 / 暂停 / 已完成。
- **截止日期**：设置或清除。
- **关联**：关联目标（点「回到目标」跳到目标）、关联人物、关联想法、关联文献。
- **里程碑航程**：「站点」就是项目的进度条目。
  - 点「添加里程碑」，写名字，选状态：未开始 / 进行中 / 已完成。
  - 点已有的站点可以改状态。
- **任务栏**：项目下的任务列表，每条可以勾选完成、点名字打开任务。
  - 任务栏旁边的 `+`，或列表下面的输入框，直接给这个项目新建任务；认得 `明天 !高 #标签`、`@人`。
  - 输入 `@`、`#`、`!` 同样弹候选，选中后直接关联；在这里写 `#别的项目` 会把任务挂到那个项目。
- **展开项目 Markdown**：在 Obsidian 标签页里打开这个项目的笔记。
- **生成沟通准备页**：给项目里的某个人生成一页「与某某的沟通准备」，汇总你和这个人待沟通的任务。

### 4.4 在任务页里看项目

任务页左边的「项目」列表里，列出所有进行中、计划中、暂停的项目和未完成任务数；任务右键菜单里的「关联项目」也能直接关联。

## 五、思索页（想法与规划）

思索页有两种模式，用页面上方那座**灯塔**切换：

- **灯塔熄灭**：想法流（记想法、看想法）。
- **灯塔点亮**：规划（目标，以及按天排开的任务和日程）。

顶部的天空是这一页的装饰：夜里是星空、白天是晴空，岸边的灯塔就是切换开关。点亮时，天空上会画出一年中每一周的弧线，当前这一周用红色标出。

### 5.1 想法模式

**记一条想法**

1. 在顶部输入框「现在的想法是…」里写，`Enter` 保存，`Shift + Enter` 换行。输入 `#` 会弹出已有的想法标签（`@` 弹出人物），选一个插入；不选、直接打新名字，保存时就按新标签建立。正文里的 `#标签` 保存时会变成这条想法的标签，不留在正文里。
2. 想给它带标签：点输入框下面的**星星图标**，展开标签选择，点选已有标签，或在里面输入新标签。选中的标签会跟着这条想法一起保存。
3. 点右边的「记下」也可以保存。

**想法卡片**

每条想法是一张卡片，从上到下是：

- **第一行**：日期、**标签**、关联项目图标、成熟度星星。
- **标题**：点标题，展开这条想法的全文；再点收起。想修改内容，点「展开想法的 Markdown」，在 Obsidian 标签页里打开这篇笔记编辑。想法正文里的网页链接可以直接点击打开。
- **摘要**：没有展开时显示第一段。

**改标签（可以有多个）**

- 想法没有标签时，标签的位置是一个小短横「—」；有标签时，那里显示标签文字。
- 点这个位置（短横或任意一个标签），卡片里展开一个小面板：
  1. 最上面是这条想法**现在有的标签**，每个后面有 ×，点一下就去掉。
  2. 中间是输入框「输入新标签，回车确认」。
  3. 下面是**所有已有的标签**，按使用次数排序，已经加在这条想法上的前面有 ✓。点一下是加上，再点一下是去掉。输入文字时会按内容筛选。
  4. 输入的名字不存在时，会多出一个虚线框的「新建「名字」」，点它或直接回车，就创建并加上。
- 回车的规则：
  - 用 `↑` `↓` 选中了某个标签，回车就加上它（已经有的会去掉），并关闭面板。
  - 输入框里写了字，回车就加上这个标签，并关闭面板。
  - 什么都没输入，回车只是关闭面板。
- 一条想法可以有**好几个标签**，都会保存到笔记的 `tags` 属性里。
- `Esc` 或点面板以外的地方，也会关闭面板。去掉所有标签后，位置恢复成小短横。

**想法的成熟度**

- 点卡片上的**星星**，选想法的状态：**萌芽、发展中、成形、已采用、搁置**。星星的样子会随状态变化。
- 「已采用」和「搁置」的想法会被收起、变淡，不占版面；想看它们，在左边的状态统计里点对应状态。

**关联项目**

- 点卡片上的路线图标，选一个或多个项目，再点「完成」。
- 关联后，在大脑页里这条想法会显示标题，并连一条线到项目。

**左边的筛选栏**

- **日期热力图**：一格一天，记过想法的日子会有颜色。点一格，只看这一天的想法，再点或点「清除日期筛选」取消。
- **标签列表**：每个标签后面是它下面有几条想法。点标签，只看带这个标签的想法；一条想法有几个标签，都会被筛到。点最上面的「全部」回到所有想法。
  - 列表的高度会根据你有几个标签自动变化，「新建标签」输入框紧跟在最后一个标签后面。
  - 点「全部」右边的**铅笔**进入编辑状态：每个标签旁出现删除按钮，删除标签只是把标签从想法上拿掉，**笔记保留**。
  - 在底部「新建标签」里输入名字，回车创建一个新标签。
- **想法状态统计**：萌芽、发展中、成形、已采用、搁置各有几条，点一个就只看这个状态的想法。

**周记**

点「展开本周周记」，查看这一周的汇总。

### 5.2 规划模式

**目标行**

- 页面上排着你的目标，每页最多三个，多了可以左右翻页；达成的目标自动收起，点「已达成」再展开。
- 每个目标是一个小卡片，**名称、本周投入进度条、截止日期都在同一行**：位置放不下时，先把进度条压窄，再把名称截成「……」，日期始终完整显示。
- 暂停的目标显示「暂停，恢复于某天」，已达成的目标显示对勾和达成日期。

**新建和修改目标**

- 目标行末尾的 `+`，输入名字回车。
- 点目标打开详情纸，可以改：
  - 名称、**每周计划投入**（小时，每次加减 0.5）、**截止日期**。
  - **状态**：进行中 / 暂停到某天 / 达成。
  - **关联项目**：关联或取消关联，并看到本周每个项目投入了几个小时。
  - 删除目标：5 秒内可撤销。

**按天看任务**

- 下面按天排开，每一天显示当天的任务和订阅的日历日程；点「在这天记一件任务」直接新建。
- 把任务拖到某一天，就改变它的日期，拖动时有虚线落点。日期只通过拖放调整。

**本日寄语**

每天可以写一句话，`Enter` 保存，`Shift + Enter` 换行；它存在当天日记的 `quote` 属性里，也会在复盘页里看到。

## 六、今日页

今日页是你一天的工作台。

### 6.1 页面包含的内容

- **日期、星期、第几周、时间**。
- **时间轴**：0 点到 24 点，显示你订阅的日历日程和当天的随手记。鼠标移到日程浮标上，可以看到时刻、名称和说明。
- **今日聚焦**：把今天最重要的**一件**任务放大显示，旁边有「完成」按钮。
  - 还没有聚焦时，点「挑选今日重点」，从今天的任务里选一个。
  - 想**更换**：点「今日聚焦」这四个字，下面列出其他还没完成的任务，点一个就换成它；原来的聚焦标记会取消。换完左下角有「撤销」，5 秒内可以撤回。再点一次标题，或点「收起」，关闭这个列表。
  - **聚焦跟着顺序走**：今日页「其他任务」里的任务可以拖动调整顺序，也可以拖到聚焦那一块的前面或后面。调整之后，**这一天排在最前面的未完成任务会自动成为今日聚焦**；用标题换聚焦时，被选中的任务也会同时排到最前面，两边保持一致。
  - 聚焦会写进任务笔记的 `focus` 属性，顺序写进 `order` 属性；没有人选时，潮线会自动把最早到期的未完成任务设为聚焦。
- **今日任务**：直接在输入框里输入「输入今日任务，回车继续添加」，回车保存并接着输入下一条；也可以勾选完成。重复任务完成后会顺延到下一次。已安排时间的任务会单独列出。
- **随手记**：「记下此刻想到的事」。输入行「想到了什么？」**固定在页面右下角**，页面上下滚动时它一直在那里，随时可以写，回车保存。
- **习惯**：每日习惯打勾，旁边显示最近 7 天的完成情况（设置里可关闭）。
- **每日问题**：每天的自问，给自己打分。
- **睡眠**：填入睡和起床的日期时间，自动算睡眠时长。
- **今日投入**：「填写今日投入」，选择任务、项目或目标，填这一天累计用时（小时或分钟），可以添加多项、删除。
- **航迹**：完成的事会在这里连成一条航迹。
- **往年今日**：明年的今天，会在这里遇见今天；没有内容时显示一幅小插图。

### 6.2 常用操作

- 点任务名可以打开这篇任务的笔记；点勾选框完成。
- 今日页里完成重复任务，和任务页一样：留一份完成记录，原任务顺延。
- 今天的任务全部完成时，画面会画出一片远岸。
- **菜单顺序**：可以拖动调整今日页各块的顺序。
- 没有任务的一天，页面也会画出远岸和空状态的小插图。

## 七、复盘页

日、周、季是同一本日志的三种读法，页面里有切换。

### 7.1 日

- 按天翻页，看某一天：
  - 完成了几件、共几件，点任务名打开任务。
  - 本日寄语、随手记。
  - 每日习惯和睡眠时长，当日状态评分。

### 7.2 周

- 本周完成的任务数。
- 平均睡眠、习惯达成率、状态均值、记录了几天。

### 7.3 季

- **整体趋势**：任务完成数和深度投入。
- **时间投入分布**：按领域统计这个季度的投入。
- **生命之轮**：本季度各领域的评分。用鼠标拖花瓣评分，也可以用方向键或回车；点「清除评分」重置。
- **本季靠岸（主要收获）**：自动算出，页面上不能直接编辑。读的是 `目标/` 里的目标笔记：`status` 是已达成，并且 `completed`（完成日期）落在本季度内的目标，会列在这里。
- **下一程航向（下季度方向）**：自动算出，页面上不能直接编辑。读的是 `目标/` 和 `项目/` 里的笔记：`due`（截止日期）落在**下一个季度**内，并且还没完成、没归档的，会列在这里。
- 带 `example` 标签的示例笔记不参与这两块的计算。
- **试航计划**（可编辑）：读的是季度笔记 `潮线/季度/年份-Q几.md` 的 `experiments` 属性，在页面上编辑会写回这篇笔记。
- **航海日志**（可编辑）：读的是同一篇季度笔记的正文第一段，在页面上编辑会写回。文字多时会**自动缩小字号**，保证全部文字都显示在框里；缩到最小（10px）还放不下时，才在框里上下滚动。
- **生命之轮**的评分读的是季度笔记的 `wheel` 属性，各领域的名字来自 `潮线/配置.md` 的 `areas`。
- 航行数据、航速、配舱是自动从任务、日记、书籍里统计的，不用手填。
- **打开季度复盘笔记**：在 Obsidian 标签页里打开 `季度/` 里的这一季笔记。
- 复盘里记下的成就，可以撤销。

## 八、知识库页

知识库管文献和书。

### 8.1 深海视图

- 页面是一片深海，**绳结代表阅读深度**，旁边写着深度范围。
- **纸签**是一本书或一篇文献，**上下拖到别的绳结**，就改变它的阅读阶段。
- 点纸签展开详情，点「回到深海」返回。

### 8.2 浏览与筛选

- **搜索**：搜标题、作者、关键词，也能搜笔记。
- **项目筛选**：在文献或书的详情里，点「关联项目」旁边的项目，顶部会出现一个带项目图标的标签（样子和旁边的 Zotero、知识库按钮一样）。这时关联了这个项目的文献和书保持正常颜色，**其他的会变淡**（淡到约 30%），不会被隐藏，位置也不变。点这个标签，或标签上的 ×，就取消筛选。
- **文献 / 书籍**两类分别显示；没有内容时会写一句怎么开始。
- **收藏**：点书籍或文献旁的书签收藏；再点取消收藏。

### 8.3 详情

可以编辑或查看：

- 阅读阶段（含「放弃」）。
- 一句话结论。
- 关键词（用顿号、逗号、分号或换行分隔，回车保存）。
- 关联项目。
- 当前页和总页数，或阅读进度百分比；预计完成日期。
  - **书的阅读阶段会跟着进度自动变**：进度到 100%，或者当前页等于总页数，状态自动从「想读」「在读」变成「读完」，并记下读完的日期；进度从 0 变成有（或当前页不再是 0），状态自动从「想读」变成「在读」；进度改成 0 或者清空，状态自动回到「想读」（原来是「读完」的，读完日期也一并清掉）。已经标成「放弃」的书不会被自动改动。这个规则只对书籍生效，文献的阶段（待泛读、已泛读、待精读、已精读）仍然手动调整。
- 标签：「+ 添加标签」，也可以移除。
- 我的笔记、我的标注、关键信息、相关内容；编辑已有笔记时，回车保存，`Shift + 回车` 换行。
- **摘要最多显示第一段**：摘要有好几段时，只显示第一段，下面出现「展开 ▽」，点开看全部，再点「收起 △」。**关键信息**每一条最多显示两行，超出的那一条后面也有「展开 ▽ / 收起 △」；没被截掉的不会出现这个提示。
- **阅读模式**：详情里「摘要」「笔记」「标注」「相关」四个标签页的文字，都按 Markdown 的阅读模式显示：分段、编号和项目列表、引用、加粗、`[[链接]]` 都正常渲染，不会再挤成一整段；点里面的 `[[链接]]` 会打开对应的笔记。里面写的各级标题（`#`、`##`……）也会按阅读模式显示，但**最大的一级标题也不会超过文件标题的大小**，往下逐级变小，不会把页面撑得很乱。
- **版面高度**：详情页右边一列（阅读进度、我的标签、读书笔记、相关内容、关联项目）按「一本普通的书」的高度来排，窗口不够高时整页加长，可以上下滚动，海底的风景留在最下面完整显示。比这更长的内容（比如标签很多），右边一列和中间的详情照旧在框里自己滚动。
- **标题不会比页面标题大**：想法正文、知识库和任务正文（Obsidian 自带编辑器）里 Markdown 的标题，一级标题最大 18–20px，往下逐级变小，都不会超过页面标题。
- **输入框下面的格式按钮**：**B** 加粗、*I* 斜体、**≡** 把选中的行变成项目列表、**↗** 插入 `[[笔记链接]]`。先选中文字再点按钮，就给选中的文字加上格式；没选中，就在光标处放一对符号，光标停在中间。
- **读书笔记**：在书籍的笔记里添加 `[[笔记名]]`，这里会自动显示分支，可以展开或折叠。
- **打开 PDF**：有本地 PDF 时直接打开；没有时在 Zotero 里打开。
- **展开笔记 Markdown**：在 Obsidian 标签页里打开这篇笔记。

### 8.4 Zotero

- 如果装了 Zotero Integration 插件，它导入的文献笔记会出现在知识库。
- 页面上的「Zotero」按钮会调用它的导入功能。
- 在 设置 › 笔记 里可以指定 Zotero 导入文件夹。

## 九、大脑页

大脑页把你所有的内容画成一棵「树」，看它们之间的关联。

### 9.1 顶部

- 一排**类型按钮**：全部、目标、想法、项目、任务、文献、人物。点哪个就只看哪一类，再点一次回到全部。
- 按钮下面有一行**淡色说明**，说明当前这一类显示的是什么：
  - 全部：「默认只列重点：进行中的目标和项目、已关联的想法、今天和高优先级的未完成任务、收藏的文献和书、相关人物。」
  - 目标 / 想法 / 项目 / 任务 / 文献 / 人物：各写「全部……共几个」，数字随你的数据自动变化。
- 右上角工具：搜索、定位（清除选中并回到全部）、列表视图切换、缩放（80% 到 120%）。
- 顶部这一块在页面滚动时**固定在顶部**。

### 9.2 默认视图（树状）

默认只列「重点」，不是全部：

- **目标**：只列进行中的。
- **想法**：只列已关联项目的；没关联的不显示。
- **项目**：只列状态是「进行中」的（计划中、暂停的不算）。
- **任务**：只列今天的、以及优先级为「高」或「最高」的，而且必须是**未完成**的；已完成、已取消的不显示。
- **文献、书**：只列你收藏的。
- **人物**：只列和进行中的项目、或未完成任务有关联的人。

树冠里有四个区域标题：**方向与想法**（目标、想法）、**项目与任务**、**人际**（左右各一个）、**知识**（文献和书）。

- 每一类节点待在自己标题下面的区域里，在区域里**随机错落摆放**，互不重叠、不压标题。
- 位置是按节点固定的，每次打开都一样；节点特别多放不下时，会整体缩小一些（最小缩到 60%），保证不重叠。
- 人物在左右两侧，按「左、右、左、右」交替，从上到下排；一侧排不下，会往里再排一列。
- 点四个标题可以**折叠或展开**这一类的所有节点：
  - 「方向与想法」折叠目标和想法。
  - 「项目与任务」折叠项目和任务。
  - 「知识」折叠文献和书。
  - 「人际」折叠所有人物，左右两个「人际」是同一个开关。
  - 折叠后，标题变灰，旁边显示一个向右的小三角和被收起的数量；再点展开。
  - 折叠只影响树的显示，不改动任何数据。

### 9.3 节点的样子

- **项目**：文字最大。
- **任务**：字稍小，颜色稍浅。
- **子任务**：和任务同样大小，颜色最浅。
- **想法**：只在「想法」视图里，未关联项目的想法只画一颗星，不写内容，鼠标移上去能看到标题。
- 文字较长的节点会平衡换成两行，框宽贴着文字。
- 子任务会用一条线连到它的父任务。

### 9.4 选中与跳转

- **点一个节点**：选中它，高亮它和所有与它相连的线，其余变淡。再点取消。
- **双击节点，或选中后按 `Shift + Enter`**：回到这个对象所在的页面（项目回项目页，任务回任务页，想法回思索页等）。
- 点 **定位**按钮，清除选中和筛选。

### 9.5 线是怎么来的

树上的线只来自这几种关系：

- 项目 — 目标、想法、文献、人物、任务。
- 书 — 项目。
- 父任务 — 子任务。

没挂到任何项目的节点就没有线。想法要和项目关联，可以在思索页想法的「关联项目」里选，也可以在项目笔记的 `ideas` 属性里写上这条想法。

### 9.6 高关联节点榜单

右边的「高关联节点」面板，列出**连线最多的节点**，最多 12 个，右边的数字是连线的条数。

- 点榜单里的一项：在树上选中并高亮它；如果当前视图里没显示，会把它加进来。
- 点标题旁的「›」收起面板。
- 已完成、已取消的任务不会出现在榜单里。

### 9.7 列表视图

点右上角的三条杠按钮切换。列表按类别分组：**目标、想法、项目、任务、文献和书、人物**，每组前面有类别标题和数量。

- 「任务」下面还有两个可折叠的区：**已完成** 和 **已取消**，默认折叠，点开才显示：
  - 已完成：每条前面是打了勾的圆圈，名字有删除线、颜色变灰。
  - 已取消：每条前面是画了叉的圆圈，名字同样有删除线。
- 点列表里的条目，和点树上的节点一样，可以选中。
- 内容多时，框随内容增高，整页可以上下滚动。

### 9.8 页面滚动

大脑页比窗口略高，整页可以上下滚动；树的大小和树干长度保持不变，整棵树一起移动。

### 9.9 搜索

点搜索按钮，或按 `/`：输入关键词，节点会筛选成匹配的（匹配标题和正文）；搜索时所有想法都显示标题，包括没关联项目的。

## 十、指引页（AI 助手）

指引页是潮线里的 AI 助手入口，需要先在设置里接入一个 AI 代理。

### 10.1 页面构成

- **提示词库**：左边可以搜索（「搜索提示词」）和选择你保存的提示词。
- **对话区**：右边是对话。输入框里写下问题，或补充你的思路，**用 `@` 提到笔记**，可以把某篇笔记作为上下文。
- 指引只会附带你**实际打开的 Markdown 笔记**，可选自动附带当前页的内容。

### 10.2 发送与保护

- 发送方式在设置里选：回车发送，或 `Ctrl + 回车` 发送。
- 回答里只保留网页、邮件和页内链接，图片不自动加载，会显示成可点的「[图片：说明]」。
- 对 AI 的权限分三档：**只读**、**改前确认**、**自动接受改动**。可以设置「不能改的位置」和「允许直接改的文件夹」，改动可以回退。

### 10.3 接入 AI

- 潮线是一个 ACP 客户端，可以接 Claude Agent、Codex、Gemini CLI、CodeBuddy、DeepSeek Harness，或自定义代理。
- 在 设置 › 指引 里逐家开启、检查，可选「默认模型」和默认思考强度。
- 对话保存在这台设备上，可以清除对话列表（各家代理自己的会话记录不会被删除）。

## 十一、设置

左侧栏的「设置」打开设置页；Obsidian 的 设置 › 第三方插件 › 潮线 里也能进。设置页分六个分页。

### 11.1 设备（只在这台设备上，不同步）

- **字号**：标准 / 特大。
- **配色**：纸本 / 夜航（深色）。
- **过场**：滑动 / 关闭。
- **打开时停在**：上次所在的页 / 今日 / 思索。

- **悬停功能提示**：默认关闭，打开后鼠标停在图标上有说明。

### 11.2 指引

- 启用 AI 助手，选默认供应商。
- 每家供应商：接入方式、启动命令、参数、默认模型、API 密钥（可选）、登录状态。
- 权限与保护：只读 / 改前确认 / 自动接受；不能改的位置；允许直接改的文件夹。
- 技能与命令、MCP 服务。
- 对话的发送方式、自动归档（7 天 / 30 天 / 90 天 / 不归档）。

### 11.3 笔记

- 各类笔记的**文件夹**：任务清单、日记、任务、项目、人物、目标、想法、文献、书籍。
- **随手记标题**（默认「## 随手记」）。
- 管理**习惯**、**每日问题**、**生命之轮领域**：新增、改名、更多。
- **Zotero 文献**：接入 Zotero，指定导入文件夹。

### 11.4 日历

- 添加 **iCal 订阅地址**，给订阅起名字，设置刷新间隔（点一下换），点「立即刷新」马上去取。
- 订阅的日程会出现在今日页时间轴和思索页的规划里。
- 取回的日程存在这台设备上，到了刷新间隔才重新联网；服务器说请求太频繁时，会按它说的时间再试，期间继续显示上次的结果。
- 地址是私密信息，设置里默认隐藏。

### 11.5 数据

- **索引、检查**：检查链接指向不存在的笔记、日记里有清单里没有的习惯或问题等一致性问题。
- **同步冲突副本**：列出可能的冲突副本。
- **示例航程**：清除示例笔记（会进 Obsidian 回收站）。

### 11.6 关于

版本、**重新起航**（重新走一遍首次引导），以及「支持潮线」，潮线免费开源。

## 十二、附录

### 12.1 任务快速输入语法

在任务页的新建框、项目页的任务栏、右上角「记录」里写任务时，下面这些都会被自动识别，识别后就从标题里拿掉，标题只留下剩下的文字。

**日期**

| 写法 | 含义 |
| --- | --- |
| `今天` `今日` | 今天 |
| `明天` `明日` | 明天 |
| `后天` | 后天 |
| `大后天` | 三天后 |
| `下周` `下星期` | 七天后 |
| `周三` `星期三` `礼拜三` | 最近的那个周三 |
| `下周三` | 下周的周三 |
| `下个月` `下月` | 一个月后 |
| `3天后` `三天后` | 几天后 |
| `2026-12-01` | 指定日期 |
| `12月1日` `12月1号` | 指定月日（已过的自动算明年） |
| `12/1` | 指定月日 |

**时刻**

- `下午3点`、`晚上8点半`、`上午十点二十`、`15:30`。
- **起止时间**：`9:00-10:30`，结束时间必须晚于开始时间，同一天内。
- 写了时刻但没写日期，日期默认是今天。

**优先级**

- `!高`、`!中`、`!低`、`!最高`；或 `!!` 表示高，`!!!` 表示最高。

**符号**

- `#清单名`：放进这个清单；`#项目名`：挂到这个项目；`#标签`：加标签（清单、项目都没有这个名字时当标签）。
- `~清单名`、`^清单名`：放进清单。
- `@人名`：挂给这个人待沟通（名字不存在时，在候选里选「新建人物」）。

**重复**

- `每天`、`每周`、`每月`、`每年`、`工作日`。
- `每周三`、`每周一三五`。
- `每2天`、`每两周`、`每3个月`。

**例子**

`周五下午3点交报告 !高 #学习 @小林 每周`

### 12.3 笔记里的属性对照

潮线读写的是笔记顶部的属性（frontmatter）。你可以在 Obsidian 里直接改。

**任务**（`任务/`）

| 属性 | 含义 |
| --- | --- |
| `status` | 状态：`open`、`done`、`cancelled` 等 |
| `scheduled` | 日期 |
| `priority` | 优先级：`highest` `high` `medium` `low` |
| `project` | 所属项目，写成 `[[项目名]]` |
| `list` | 所在清单名 |
| `people` | 待沟通的人，`[[人名]]` 列表 |
| `discuss` | 是否待沟通 |
| `tags` | 标签 |
| `repeat` | 重复规则 |
| `parent` | 父任务，写成 `[[任务名]]`（有这个就是子任务） |
| `completed` | 完成日期 |
| `order` | 排序号 |
| `focus` | 是否是今日重点 |

**项目**（`项目/`）：`status`（`planned` `active` `paused` `completed`）、`due`、`goals`、`people`、`ideas`、`literature`。

**目标**（`目标/`）：`planned`（每周计划投入小时）、`due`、`status`、`resume`（暂停到哪天）、`completed`。

**人物**（`人物/`）：`initial`（头像字）、`cadence`（多少天联系一次）；笔记里的「## 记录」记着每次联系。

**想法**（`想法/`）：`created`、`stage`（成熟度）。

**书籍**（`书籍/`）：`authors`、`type`、`stage`、`year`、`added`、`started`、`currentPage`、`totalPages`、`keywords`、`projects`。

**日记**（`日记/`）：`quote`（本日寄语）、`effort`（今日各事项投入的小时）、`tags`；随手记写在正文「## 随手记」下。

### 12.4 小贴士

- 任务、项目、人物之间的关联，都是 `[[链接]]`，你在 Obsidian 里点这些链接也能跳转。
- 删除任务、目标、人物，笔记都会进 Obsidian 回收站，可以找回。
- 如果在 Obsidian 里直接改了笔记，潮线会自动读到；如果改的是潮线正在显示的那条任务，潮线会等你停手再刷新，光标不会乱跳。
- 在中文输入法下打拼音时，潮线的候选菜单和回车都不会打断输入。
- 想重新看一遍首次引导：设置 › 关于 › 重新起航。

## 十三、常见问题

**为什么大脑页里看不到我的某个任务？**
默认视图只列重点：今天的、和优先级为「高」「最高」的未完成任务。已完成、已取消的任务树上不显示。想看全部未完成的任务，点上面的「任务」按钮；想看已完成的，切换到右上角的列表视图，在「任务」下面展开「已完成」。

**为什么大脑页里有的想法只有一颗星？**
没有关联任何项目的想法，默认视图里不显示；点上面的「想法」按钮时，它们只画一颗星，不写内容。给它关联一个项目后，就会显示标题并连线。

**为什么大脑页里的项目比我的项目少？**
默认视图只列状态是「进行中」的项目；计划中、暂停、已完成的，点上面的「项目」按钮可以看到。

**任务页的搜索为什么搜到了不在当前清单里的任务？**
搜索是在所有任务里查找的，不受左边选中的清单限制。要只看某个清单，先清空搜索框。

**在任务正文里输入 `@`、`#` 没有反应？**
这两个符号要出现在**行首或空格后面**才会弹出候选；`a@b.com`、`C#` 不会触发。

**拼音输入过程中，按回车为什么没有直接保存？**
这是故意的：输入法还在组字时，回车只用来确认汉字，不会触发保存或选中候选。

**我改了任务正文，多久保存？**
停手约 1 分钟后自动保存；点到别处、切换窗口、关闭页面时会马上保存。

**想法卡片上点标签，为什么不是筛选了？**
卡片上的标签现在用来**修改**这条想法的标签。要按标签筛选，用左边的标签列表。

**怎么把某个人和某个项目关联？**
在项目详情里关联人物；也可以在任务里用 `@人名` 把任务挂给他，这样他和任务相关，也会在大脑页的人物里出现。

**删了任务还能找回吗？**
5 秒内可以点「撤销」；之后笔记会进 Obsidian 的回收站，可以在那里找回。

**我想重新看一遍首次引导？**
设置 › 关于 › 重新起航。
