# 示例笔记

这是一个**完全虚构**的小 vault，用来演示潮线的笔记结构，里面没有任何真实的个人内容。

## 怎么用

1. 新建一个空的测试 vault（不要用你正在用的 vault）。
2. 安装并启用本仓库的插件（见根目录 README）。
3. 把 `vault/` 里面的所有文件夹，整个复制到测试 vault 的根目录。
4. 在 Obsidian 里运行命令「打开潮线」。

## 说明

- 每篇笔记的属性里都带着 `example` 标签，所以在潮线里会用淡墨和一个「例」字标出，**不计入统计**。
- 想一次清掉：设置 › 数据 › 清除示例。
- 示例里的日期是 2026 年底，如果日期过去了，打开任务页，把它们拖到今天就行。
- 各类笔记的属性对照，见 `docs/使用说明.md` 的「附录 › 笔记里的属性对照」。

## 文件夹对应

| 文件夹 | 内容 |
| --- | --- |
| `任务/` | 任务，含一条子任务（`parent`）、一条已完成的任务 |
| `项目/` | 一个进行中、一个计划中的项目 |
| `目标/` | 一个每周投入的目标 |
| `人物/` | 两个人物，带联系频率 |
| `想法/` | 一条关联了项目的想法、一条没有标签也没有关联的想法 |
| `书籍/` | 一本在读的书 |
| `日记/` | 一篇带本日寄语和随手记的日记 |
| `潮线/配置.md` | 清单、快捷筛选、习惯、每日问题 |
