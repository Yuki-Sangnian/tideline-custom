# Tideline（潮线）· 修改版

一个 Obsidian 插件：把你的任务、项目、目标、人物、想法、书和日记，画成一本手绘的「航海日志」来操作。所有数据都是你 vault 里的普通 Markdown 笔记。

本仓库是 **Tideline 0.9.7 的修改版**：在原插件基础上，改进了任务页、项目页、思索页和大脑页的一批功能（详见 [CHANGES.md](CHANGES.md)）。

> **关于这个仓库**
> - 原作者：潮线 (Tideline)，MIT 协议，见 [LICENSE](LICENSE)。
> - 这里没有源码构建流程：改动是直接在打包后的 `main.js` 和 `styles.css` 上做的，所以仓库里只有这两个文件加 `manifest.json`。
> - 仓库里**不含任何个人笔记**，`examples/` 里是完全虚构的示例。

## 安装

**手动安装**

1. 关闭 Obsidian 里正在使用的旧版（如果有）。
2. 把本仓库的 `main.js`、`styles.css`、`manifest.json` 三个文件，复制到你的 vault 里的 `.obsidian/plugins/tideline/` 文件夹（没有就新建）。
3. 重启 Obsidian，在 设置 › 第三方插件 里启用「Tideline」。
4. 运行命令「打开潮线」。

> 覆盖前建议先备份原来的 `main.js` 和 `styles.css`。

**用 BRAT 安装**

如果仓库发布了 Release（附带上面三个文件），可以用 BRAT 插件，添加本仓库的地址安装并更新。
